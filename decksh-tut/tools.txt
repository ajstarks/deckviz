In order to make presentations with decksh you will need some tools: 
\n
(1) the decksh command-line tool
(2) a text editor to compose and edit the decksh code
(3) a command line to execute decksh commands
(4) a viewer program to see the results
\n
See "Installing and Running decksh/pdfdeck” (https://speakerdeck.com/ajstarks/pdfdeck) for installation instructions.
\n
Any editor that works with plain text files can be used to compose decksh code.
Examples include vim, VS Code, Sublime Text, zed, BBEdit, and micro.
All of these editors have syntax highlighting support for decksh.
\n
The general workflow is to compose your decksh code in the
text editor, invoke the command to make the result, and then 
show the results in your viewer. (lines beginning with '$' are the command line prompt)
\n
$ decksh first.dsh > first.xml
\n
$ pdfdeck first.xml
\n
$ open first.pdf
\n
Note that editors such as VS Code and Sublime Text may be configured to automate these steps, so that you only need to execute a keystroke or save the decksh file to see the new result.
